# Branding

The app uses the existing official ArchiveBox organization logo unchanged:
https://avatars.githubusercontent.com/u/74894248?v=4

The original 450×450 image is embedded in an Icon Composer `.icon` source and in the in-app BrandLogo image set. Xcode renders the platform icon sizes; the original artwork is not regenerated or redrawn. The app accent color is sampled from the logo background in sRGB. The icon source supports Apple’s shared square enclosure for future iOS/macOS packaging.
